# Expense Tracker

A simple command-line expense tracker written in Python.

## Features

* Add expenses
* View all expenses
* Delete expenses
* Calculate total expenses
* Save data using JSON

## Requirements

* Python 3.x

## Run

```bash
python main.py
```

## Example

```text
=== Expense Tracker ===
1. Add expense
2. Show expenses
3. Delete expense
4. Exit
```
